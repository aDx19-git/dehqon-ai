# 🌾 Dehqon AI

> 🇺🇿 O‘zbekiston dehqonlari uchun aqlli Telegram yordamchi

Dehqon AI — dehqonlarga ob-havo, ekinlar, teplitsalar va AI maslahatlari bo‘yicha yordam beruvchi Telegram bot.

## ✨ Imkoniyatlar

- 🌤 Real ob-havo ma'lumotlari
- 🌱 Ekinlar bo‘yicha tavsiyalar
- 🏡 Teplitsa tahlili
- 🧠 AI dehqon maslahatchisi
- 🚨 Muhim ob-havo ogohlantirishlari
- 💧 Sug‘orish va parvarish bo‘yicha maslahatlar

## 🛠 Texnologiyalar

- Python
- aiogram
- HTTPX
- OpenAI API
- Telegram Bot API
